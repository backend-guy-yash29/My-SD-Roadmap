# AI Evals, Safety & Observability

> Traditional systems are monitored on latency, availability, throughput and errors. AI systems need all of those, plus a measure of whether the output itself is good.

## What to Measure

- Answer Quality
- Hallucination Rate
- Groundedness
- Retrieval Quality
- Tool-Call Success
- Agent Completion Rate
- Token Usage
- Cost per Request Tracking
- Safety Violations

## Language Model Metrics

- Cross-Entropy and Perplexity
- Exact Match and Functional Correctness
- Similarity Metrics (BLEU, ROUGE, Embedding Similarity)

## Evaluation Methods

- Golden Datasets
- Human Evaluation
- LLM-as-a-Judge
- Pairwise Comparison and Model Ranking
- Agent Evaluation
- Offline Evaluation
- Online Evaluation
- Public Benchmarks and Their Limits

## Production Evaluation

- A/B Testing Prompts and Models
- Prompt Versioning
- Model Versioning
- Tracing

## AI Safety & Security

- Hallucination Mitigation
- Prompt Injection
- Indirect Prompt Injection
- Jailbreaking
- Data Leakage
- PII Exposure
- Tenant Isolation
- Input and Output Guardrails
- Red Teaming
