# Model Evaluation & Selection

> Measuring classifiers properly, validating fairly, tuning hyperparameters and handling imbalanced data.

## Classification Metrics

- Accuracy and the Confusion Matrix
- Type I and Type II Errors
- Precision, Recall and F1 Score
- ROC Curve and ROC-AUC
- Precision-Recall Curve and PR-AUC
- Multi-Class Metrics (Macro, Micro, Weighted)
- Ranking Metrics (NDCG)

## Validation

- Cross-Validation (K-Fold, Stratified)
- Probability Calibration

## Hyperparameter Tuning

- Grid Search and Randomized Search
- Bayesian Optimization (Optuna)

## Imbalanced Data

- Class Imbalance
- Undersampling and Oversampling
- SMOTE
- Class Weights and Threshold Tuning

## Practical Tips

- Diagnosing Bias vs Variance from Learning Curves
- Error Analysis
